## A1. Verdadero o Falso

| Nº | Afirmación | V / F |
|:---:|---|:---:|
| 1 | La etiqueta `<img>` se cierra con `</img>`. | F |
| 2 | El atributo `alt` muestra un texto si la imagen no se puede cargar. | V |
| 3 | Para dar ancho y alto a una imagen se recomienda usar `style` en lugar de `width` y `height`. | F |
| 4 | La propiedad `float` permite que una imagen flote a la izquierda o a la derecha del texto, o que no flote. | V |
| 5 | El rótulo de un enlace solo puede ser un texto. | F |
| 6 | `target="_blank"` hace que el enlace se abra en una ventana (pestaña) nueva. | V |
| 7 | Por defecto, un enlace ya visitado se ve azul y uno por visitar, morado. | F |
| 8 | Un enlace relativo escribe la URL completa, incluido el dominio. | F |

---

## Corrección de las afirmaciones falsas

**1.** La etiqueta `<img>` no necesita etiqueta de cierre, porque es una etiqueta vacía.

**3.** Para indicar el ancho y el alto de una imagen podemos utilizar los atributos `width` y `height`. También podemos utilizar CSS con `style`.

**5.** El rótulo de un enlace puede ser texto, una imagen u otro contenido HTML.

**7.** Por defecto, un enlace por visitar suele aparecer azul y uno ya visitado, morado.

**8.** Un enlace relativo no escribe la URL completa, sino una ruta relacionada con la ubicación del documento actual.
