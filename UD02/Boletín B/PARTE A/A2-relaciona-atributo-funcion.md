## A2. Relaciona atributo y función

| Elemento | Descripción | Respuesta |
|:---:|---|:---:|
| 1. `src` | A. Crea un marcador (bookmark) dentro de la página | D |
| 2. `alt` | B. Indica el destino del enlace | G |
| 3. `href` | C. Valor de `target` que abre una pestaña nueva | B |
| 4. `target` | D. Ruta del archivo de imagen | F |
| 5. `id` | E. Propiedad CSS para que la imagen flote junto al texto | A |
| 6. `float` | F. Indica dónde se abrirá el destino del enlace | E |
| 7. `_blank` | G. Texto que se muestra si la imagen no carga | C |
