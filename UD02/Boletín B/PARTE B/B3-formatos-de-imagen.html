¿Qué formato de imagen elijo?

Para una foto de vacaciones con muchos colores recomiendo JPEG (.jpg), porque permite guardar fotografías con buena calidad y un tamaño de archivo reducido.

Para un logo con fondo transparente recomiendo PNG (.png), porque permite utilizar transparencias y mantiene una buena calidad.

Para un icono que se vea nítido a cualquier tamaño recomiendo SVG (.svg), porque es un formato vectorial que se puede ampliar sin perder calidad.

Para una animación corta tipo meme recomiendo GIF (.gif), porque permite mostrar imágenes animadas.

Para el icono de la pestaña del navegador recomiendo ICO (.ico), porque es un formato utilizado habitualmente para los iconos de las páginas web.
