### A6. ¿Qué verá el usuario?

**1. Predicción: ¿Qué se mostrará en la página?**

Antes de comprobar el código, creo que el usuario verá lo siguiente:

- Un título principal grande que dice "Resumen de la jornada".
- Debajo, un párrafo con dos frases:
  - Ha ganado el equipo local.
  - El rival se despide del torneo.
- Una línea horizontal que separa el contenido.
- Un título más pequeño que dice "Próximo partido".
- Finalmente, un párrafo con el texto "Sábado a las 18:00".

**2. Comprobación del resultado**

Al comprobar el código HTML, se observa que el resultado coincide con mi predicción.

La etiqueta `<h1>` muestra el título principal, `<br>` hace un salto de línea, `<hr>` crea una línea horizontal y `<h4>` muestra un encabezado de menor tamaño.

**3. Código HTML:**

```html
<h1>Resumen de la jornada</h1>
<p>Ha ganado el equipo local.<br>El rival se despide del torneo.</p>
<hr>
<h4>Próximo partido</h4>
<p>Sábado a las 18:00</p>
```

He podido identificar cómo se muestra cada etiqueta HTML en la página. Mi predicción ha sido correcta porque el resultado coincide con lo que esperaba.
